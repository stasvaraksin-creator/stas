# Карточки товара — наматрасник ТЕКСПОЛИМЕР 200×90×10

Карточки для маркетплейса, 1500×2000 (пропорция 3:4), оранжевый фон бренда.
Оформление построено по системе, снятой с карточек MedicoPRO: три зоны
(шапка → инфографика → товар), белые выноски с хвостиком, круглая врезка-зум,
гекс-паттерн в углах, двухступенчатая шапка.

## Пересборка

```
pip install pillow scipy playwright
cd src
python3 water.py        # рендерит воду и тень -> product_sh.png, product_wet.png, geom.json
python3 gen.py          # собирает cards.html
python3 shot.py         # рендерит out_c1..c6.png через Chromium
```

`shot.py` берёт Chromium по пути `/opt/pw-browsers/chromium-1194/chrome-linux/chrome`
(предустановлен в этой среде). На своей машине замените путь или уберите
`executable_path` и выполните `playwright install chromium`.

## Устройство `gen.py`

- Палитра снята пиксельной выборкой с исходных карточек: оранжевый градиент
  `#CE7938 → #DF9353`, бирюзовый акцент `#2A9A88`.
- `product.png` — товар, вырезанный с фото по насыщенности с заливкой отверстий,
  так что молния и кант сохранены. `water.py` делает из него `product_sh.png`
  (с мягкой тенью по силуэту) и `product_wet.png` (с разлитой водой).
- Константы `L, B, R, F` — углы силуэта товара в координатах вырезки. Из них
  строится матрица `FACE`, которая переводит единичный квадрат в плоскость
  верхней грани. По ней посажены и лужа на карточке 02, и размерные стрелки
  на карточке 06 — поэтому перспектива совпадает с фотографией.
- Иконки — инлайновый SVG в словаре `ICONS`, обводка наследует `currentColor`.
- Шрифты (Montserrat, Golos Text) лежат в `fonts/` подмножествами
  latin + cyrillic, подключаются через `@font-face` с `unicode-range`,
  поэтому рендер не зависит от сети.

## Как считается вода (`water.py`)

Вода не рисуется заливками, а считается как прозрачная плёнка на ткани:

1. Форма лужи задаётся в параметрических координатах верхней грани, поэтому
   перспектива совпадает с фотографией.
2. По маске строится карта высот: плоская середина и скруглённая кромка
   (мениск), плюс сферические шапки капель.
3. К высоте добавляется микрорябь — она дробит блик. Без неё поверхность
   выглядит как гладкий CG-пластик.
4. По карте высот считаются нормали, по ним смещается выборка из **настоящей
   фотографии ткани** — то есть сквозь лужу виден реальный материал.
5. Сверху: блик по Блинну-Фонгу с зерном, френелевская подсветка кромки,
   затемнение и подъём насыщенности мокрой ткани.

Свет задан вектором `Lv` и совпадает с направлением света на исходном фото
(сверху-слева). Если поменяется фотография товара, `Lv` нужно пересогласовать.

## Что требует внимания перед публикацией

- **Стакан с жидкостью убран.** Векторный стакан был самым «мультяшным»
  элементом набора. Разлитая вода теперь считается физически и выглядит как
  фотография, а вот убедительный стакан синтезировать не получится — это
  твёрдотельный объект, ошибки геометрии в нём видны сразу. Если нужен стакан,
  снимите одно фото: стакан с водой на этом наматраснике, свет сверху-слева —
  вклею его в композицию.
- **Формулировка «противомикробное состояние»** перенесена дословно с
  существующей карточки. Если заявление требует подтверждения, заменить на
  «легко очищается и выдерживает дезинфекцию».

## Карта производства

`shema/index.html` — интерактивная схема производства медицинских матрасов:
план трёх помещений по 135 м² с воротами и оборудованием, семь операций от
приёмки блоков ППУ до отгрузки вакуумных рулонов, расстановка четырёх
человек и калькулятор раскроя блока на листы 2000×800.

- клик по операции или по участку плана подсвечивает маршрут материала;
- «Проиграть цикл» прогоняет все семь операций подряд;
- слои «Маршрут», «Персонал», «Размеры» включаются отдельно.

План построен по эскизу помещений; принятые допущения перечислены внизу
страницы. Фотографии производства — `shema/img/`. Страница самодостаточна:
её можно открыть файлом в браузере, с сети подтягиваются только шрифты.

## 3D-сцена цеха

`shema/scene/index.html` — зацикленная 3D-сцена производства на Three.js,
такт 48 секунд, без интерактива: камера сама обходит цех по десяти точкам.

Что происходит в кадре: фура подъезжает, разворачивается и задним ходом
встаёт под ворота 5; поднимаются рольставни, сжатые блоки ППУ выгружаются,
расправляются до полного объёма и уходят в штабель; на ЧПУ-станке нож
проходит вдоль блока и снимает лист, лист уезжает в помещение 2 на стопку
своей плотности; упаковщик приносит лист к столу, надевает чехол, пара
матрасов уходит в ВУМ-01, пресс опускается и на выходе получается рулон;
рулоны грузят в фуру через ворота 2. Четыре человека ходят по своим
маршрутам и работают руками.

Станки смоделированы по конструкции настоящих. ЧПУ-раскрой: станина с
рольгангами подачи и приёма, колонны с верхними направляющими, подвижный
портал, бесконечный ленточный нож на двух шкивах с вертикальными осями
(видны оба прогона полотна), привод, заточные головки, пульт с экраном.
ВУМ-01: рольганг подачи, планка сварки рукава, прессовая рама с
гидроцилиндрами и подвижной плитой, вакуумный насос со шлангом к траверсе,
барабан скрутки на выходе, пульт и шильдик.

Блоков ППУ в помещении 3 — стена: три ряда в глубину, четыре по фронту,
три яруса, с разбросом по цвету и лёгким разворотом. Фуры собраны из
рамы, фургона с рёбрами борта, кабины с остеклением, зеркалами, трубой и
баком, двускатной задней оси и распашных задних дверей; колёса сидят на
ступицах и катятся от реально пройденного пути (угол = путь / радиус, знак
по проекции на направление движения), а передние ещё и доворачиваются при
манёвре. Рулоны не идеальные цилиндры: геометрия мятая волной по
окружности и провисом по длине, пять вариантов на штабель плюс разброс
масштаба и наклона. Люди собраны на суставах — бедро-колено-стопа,
плечо-локоть-кисть, конические конечности, каска; в ходьбе колено
сгибается только назад, руки идут в противофазе ногам, корпус качается.

Буфер листов в помещении 2 забит, как на фото склада: шесть рядов по пять
штабелей разной высоты, по цветам плотности, часть затянута плёнкой;
листы рисуются инстансами, поэтому полтысячи листов стоят три вызова
отрисовки. Матрасы — в серо-бежевых чехлах с кантом, рядом со столом
стопка готовых. Рулоны мятные, в плёнке, на торце видна спираль намотки
(текстура из canvas на торцах цилиндра), на части — жёлтая наклейка;
штабель сложен тремя слоями с разворотом рулонов.

Стилистика — «цифровой двойник»: бетонный пол с крашеной разметкой и
названиями участков, жёлто-чёрные зоны у оборудования, сигнальные лампы,
парящие карточки с параметрами, синие дуги связей между участками.
Стена, оказавшаяся между камерой и цехом, растворяется — цех всегда видно
изнутри. Геометрия повторяет 2D-план: те же метры, те же ворота.

Three.js r128 подключается с cdnjs, остальное — инлайн.
